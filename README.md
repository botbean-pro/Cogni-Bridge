# LearnTogether — Student Prototype

A basic working React + Vite prototype based on the dashboard mockup.

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Included interactions
- Sidebar navigation feedback
- Subject cards
- Join session / view details buttons
- View all sessions
- Text size toggle
- High contrast toggle
- Dyslexia-friendly toggle
- Reduce motion toggle
- Text-to-speech / speech-to-text placeholder actions
- Support and notification feedback
- Responsive mobile layout

This is frontend-only for the hackathon prototype. Backend, authentication, database, and real-time sessions can be added next.
